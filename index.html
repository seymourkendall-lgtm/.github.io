Cross off 100

You start with 2 crossed off. Type a math move using numbers you’ve already crossed off, and the answer gets crossed off the board. You can also click a number to set it as your goal, and click it again to clear it. One operation per move, and you can use the same number twice.

Difficulty (changing it starts a new game)

  • × multiply
  • ÷ divide
  • − subtract
  • xy exponent
  • √ square root
